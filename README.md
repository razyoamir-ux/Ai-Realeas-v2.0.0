## ساخت APK انتشار (Release) با GitHub Actions

### مرحله ۱: آپلود پروژه
پروژه را با Zip2Git یا هر روش دیگری داخل مخزن گیت‌هاب خود آپلود کنید.

### مرحله ۲: اضافه کردن Secrets (خیلی مهم)

۱. برو به مخزن گیت‌هاب خود  
۲. برو به **Settings** → **Secrets and variables** → **Actions**  
۳. این ۴ تا Secret را یکی‌یکی اضافه کن:

| Name | Value |
|------|-------|
| `KEYSTORE_BASE64` | محتویات فایل `keystore_base64.txt` (که همراه پروژه هست) |
| `STORE_PASSWORD` | `varnix2026` |
| `KEY_PASSWORD` | `varnix2026` |
| `KEY_ALIAS` | `varnix` |

### مرحله ۳: اجرای ساخت
۱. برو به تب **Actions**  
۲. workflow به نام **Build Release APK** را انتخاب کن  
۳. روی **Run workflow** بزن  
۴. بعد از اتمام، فایل `app-release.apk` را از Artifacts دانلود کن

## اطلاعات کلید امضا (Release Key)

- **Alias**: `varnix`
